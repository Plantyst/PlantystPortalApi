Problem types

When a request is refused, the Plantyst Portal API answers with a problem details document (RFC 9457). Its type member identifies what went wrong and links to the page that explains it.

Authentication and authorization

TypeStatusMeaning
unauthorized 401 The request was not authorized and the API could not determine a more specific reason.
invalid-token 401 An access token was presented in the Authorization header and rejected.
invalid-credentials 401 An API key or HTTP Basic credentials were presented and rejected.
invalid-request 400 The Authorization header of the request could not be parsed.

How to read a problem document

Branch on type. It is the stable identifier of the problem: a type that has been published keeps its meaning, and new types are added next to the existing ones rather than replacing them. The title and detail members are written for people, and their wording can change at any time - never match on their text.

{
  "type": "https://apidocs.plantyst.com/errors/invalid-token",
  "title": "Invalid access token",
  "status": 401,
  "detail": "The access token expired."
}

Responses that refuse a request for a reason other than authentication - a payload that does not validate, or a resource that does not exist - are described with the operation that returns them in the API reference.
