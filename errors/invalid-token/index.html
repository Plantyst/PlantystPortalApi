Plantyst 401 Unauthorized

Invalid access token

An access token was presented in the Authorization header and the API rejected it.

https://apidocs.plantyst.com/errors/invalid-token

What it means

The request carried a token in the Authorization header, so the credentials were found - they were simply not accepted. Any of the following produces this problem type:

  • the token has expired;
  • the token is not a valid access token of this API, or its signature or audience does not match;
  • the token no longer belongs to a registered application, or the application has been removed;
  • the value is not a token at all - an API key sent as Authorization: Bearer <key> ends up here, because an API key is not an access token;
  • the authentication scheme is not one the API accepts. Use Bearer; the Token scheme is accepted as a historical alias.

The accompanying header carries error="invalid_token", which is the same information in the form defined by RFC 6750.

What to do

  • Expired token: obtain a new one with the refresh token and repeat the request. This is the only case where a retry helps.
  • Anything else: treat it as a configuration error. Repeating the request will not change the outcome. Check that the token belongs to this API, that it is passed unchanged and in full, and that the application registration is still valid.
  • Sending an API key? Use the X-API-KEY header instead - never the Authorization header. See the Authorization chapter of the reference.
  • Receiving webhooks? The authorization object of the payload names the kind of credential in authorizationType; that value is not the name of an HTTP scheme. Send a Token credential as Authorization: Bearer {value}.

Example response

HTTP/1.1 401 Unauthorized
WWW-Authenticate: Bearer realm="https://portal.plantyst.com", error="invalid_token"
Content-Type: application/problem+json

{
  "type": "https://apidocs.plantyst.com/errors/invalid-token",
  "title": "Invalid access token",
  "status": 401,
  "detail": "The access token was rejected."
}
